FloBama Mac Camera 1.4.1

IMPORTANT — replace any older install
1. Quit Terminal windows from older FloBama Mac Camera runs
2. Eject every disk named FloBama Mac Camera (including 1.0.0 / 1.1.0)
3. Delete /Applications/FloBama Mac Camera.app (move to Trash)
4. Download Mac Camera 1.4.1 from FloBama OS → Cameras (do not reopen an old .dmg in Downloads)
5. Open THIS disk (title must say FloBama Mac Camera 1.4.1)
6. Drag FloBama Mac Camera into Applications, then open it
7. Terminal must start with: FloBama Mac Camera 1.4.1

If Terminal still says 1.0.0, you are launching the old app in Applications — delete it and drag again from this 1.4.1 disk.

NDI discovery requires Local Network permission for Terminal.
When prompted, click Allow. Or open:
  System Settings → Privacy & Security → Local Network → enable Terminal

Click the Cam ● menu-bar item to see NDI source names.
The same list appears in FloBama OS → Cameras under “NDI sources on Mac”.

Leave the Terminal window open while staff use remote cameras.
