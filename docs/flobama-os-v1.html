What V1 is

FloBama OS is a single Next.js App Router application with a Supabase Postgres backend. Staff authenticate with email/password; roles are venue-scoped and enforced in both server actions and row-level security. Public consumers never read internal event rows — they hit projection views and a versioned JSON API.

The product deliberately does not edit flobamadowntown.com, Pick'em, or other production sites. WordPress embeds, OBS overlays, and kiosk displays consume FloBama OS as a source of truth for listings and screens.
